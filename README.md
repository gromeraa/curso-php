## 🎬 Screen Magic

Projeto de linha de comando sobre filmes, construído durante o curso. Nele pratiquei:

- 📥 Leitura de argumentos via terminal (`$argv` / `$argc`)
- 🔁 Estruturas de repetição (`for`, `while`)
- 🔀 Condicionais e expressões `match`
- 🧮 Arrays e funções nativas (`array_sum`, etc.)
- 🧩 Funções tipadas separadas em arquivo próprio (`require`)

```bash
php screen-magic/screen-magic.php 8 9.5 7
```
